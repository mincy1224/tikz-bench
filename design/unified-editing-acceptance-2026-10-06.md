# 统一编辑重构验收记录（2026-10-06）

## 已实现并在本机验证

- `rectangle split uses custom fill`、透明分区颜色索引、独立分区源码编辑；普通节点的尺寸约束、内边距与两种缩放模式。
- 源码事务、预览不自动保存、连续移动一次撤销；撤销后重新解析操作基线，避免旧坐标范围写回。
- 组合拖动、联合世界边界对齐、吸附辅助线、自身排除、旋转及嵌套组合缩放、保留语义作用域的取消组合。
- 普通矩形／圆／椭圆首次连接时转换为等价命名节点，保持明确锚点引用。
- 新图形／文字右栏、精确字号、双端箭头、多选箭头、单位、键盘步进、局部默认值、颜色选择及暗色窄窗口。
- 持续同类型格式刷，拒绝圆与矩形混刷，每次应用单独撤销，保留目标内容及几何。
- 新建前名称／描述表单，取消不创建，数据库活动项目名称唯一约束，并发重名拒绝。
- 有界保存队列、700ms 提交后保存、失败重试／冲突另存、项目切换隔离及草稿导出。
- 源码安装的新库选择、原库备份与留存。安装流程在隔离模拟环境验证，未在真实 systemd 安装。

## 高级组件的实际边界

Forest、PGFPlots、Circuitikz 已接入主画布自动编译、版本检查、源码属性适配器和编译副本标记。Forest 支持节点结构／分区选项，图表支持轴属性、函数／内联坐标参数及有映射的数据点拖动，电路支持识别的元件属性和直接端点。缺失几何映射时不猜测对象，保留源码、诊断及上次成功画面。手工源码编辑会清除高级选择，结构删除／提升会清除选择，避免旧位置身份误指向其他对象。

**高级引擎尚未完成完整稳定性验收。** 当前浏览器高级选择测试使用模拟 SVG；真实 TeX 钩子、几何校准、Forest 尺寸手柄、中文字体与所有电路/图表语料须在目标环境验证。任意自定义宏内部及 groupplot 不支持反向映射；高级画布的组合覆盖层、完整键盘操作、复杂变换下电路连接操作仍有待补齐，不宣称已达到整份计划的全部能力。

```bash
nvm use 22 &&

```
