# TikZ Bench 可视化与交互检查（2026-10-03）

## 结论

基础图形、分区矩形、公式与常用格式编辑已有可用基础。本轮修复了连续输入与颜色拖动的撤销行为、单位输入、编译失败恢复、Windows MathJax 加载以及右栏常用项排序。不能将当前版本描述为任意 LaTeX 的完整可视化编辑器，也不能宣称已经全面达到 PowerPoint 的交互成熟度。

## 本轮实际修正

| 检查项 | 修正与边界 |
| --- | --- |
| 字号 | 增加精确 pt 输入、增减按钮、即时预览、Esc 取消及单次撤销；多选保留每个对象的粗体、斜体等属性，不同字号显示“多个值”。标准字号预设显示其 pt 值，避免默认字号显示 9.96。任意文档类字号与自定义宏仍需真实 TeX 校对。 |
| 线条 | 增加始终可见的精确线宽、pt/mm/cm 输入与滑块；预览不保存，失焦提交，取消还原。箭头滑块也增加失焦收束事务。 |
| 颜色 | 颜色连续拖动合并为一次撤销；增加预览、提交、取消回调，线条与填色按钮有明确的无障碍名称。 |
| 常规尺寸 | 单选、多选数值及长度输入使用预览事务；支持单位、Enter 提交、Esc 取消。并非所有旧控件都已迁入同一事务实现。 |
| 悬停预览 | 恢复原值后更新事务源码标记；源码或文档变化后拒绝旧会话继续预览、提交。 |
| 右栏 | 默认宽度从 20% 提至 28%，文字、线条、填色优先，几何和变换随后；输入与按钮支持键盘焦点，窄栏控件换行，修正暗色标签对比度。保留用户已有布局。 |
| MathJax | 引擎、源码包和默认字体固定为 4.1.3；资源复制使用实际包解析路径，兼容 workspace 嵌套安装；Windows Node 加载绝对路径转为 file URL，并抛出真实初始化错误。默认字体与动态字形同源打包。 |
| 编译预览 | 增加超时、诊断和重新编译入口；移除失败脚本以允许重试；处理异步拒绝；浏览器编译结果净化。Forest、PGFPlots、Circuitikz 出现能力提示，本地工具不可用时不会静默当作完整支持。 |
| 服务端 | 自动 profile 识别中文、ctex 文档类、宏包列表中的 fontspec 和字体命令；探测四个编译工具；引擎与转换共享总超时预算。 |

- 类型检查、生产 lint 通过。
- 全量 Vitest：211 个文件、2888 项通过；两个外部语料测试因数据缺失跳过。
- 依赖统一后，MathJax、回退渲染、编译配置、安装生命周期、能力矩阵聚焦回归：42 项通过；语料测试跳过。
- 生产构建 Edge/Chromium 浏览器验证覆盖：断外网公式与逐分区编辑；双端箭头精确参数保留；字号、线宽及尺寸输入的预览、取消、单次撤销；颜色拖动；多选字号；编译失败重试；高级组件能力提示；窄窗口、明暗主题；预览不自动保存及当前草稿导出。

- 最后补测字体预设悬停：移出恢复、再次预览、提交和一次撤销通过。合计 12 个不同的聚焦浏览器场景通过，分批运行。

## 尚未完成的能力与验收

1. **真实 Ubuntu 24.04 / systemd / TeX Live 2026 验收**。Windows 构建与模拟安装不能代替它。安装器会在服务隔离环境执行工具链、中文、分区矩形、Forest、PGFPlots、Circuitikz 的 SVG/PDF 编译预检；尚无该目标机的成功运行记录。
2. **通用 TeX 可视化**。原生编辑依赖解析器和语义能力矩阵；任意自定义宏、Forest 树布局及复杂电路、图表不能承诺逐元素拖拽。真实 TeX 通道负责编译，不能反向生成完整可编辑模型。编译 SVG 当前展示第 1 页，多页编译结果的选择界面未实现。
3. **交互一致性**。高级控件还存在多种事务路径；部分英文标签尚未统一。未新增字体安装管理、完整主题色体系、浮动格式工具条等 PowerPoint 级功能。
4. **恢复闭环**。保存失败／冲突后仍需要更友好的恢复界面；项目缩略图生成未接入队列。MathJax 初始化失败后可随后续请求重试，但尚无专用重试按钮。
5. **更广泛浏览器验收**。输入法组合事件、跨文档选择切换、保存／重命名竞态、复杂短线／曲线与组合拖动尚需更全面 E2E；已有核心测试不能替代这些操作验收。
6. **前端性能**。构建仍提示较大 JavaScript 分块；未完成大型文档性能、移动设备、全浏览器兼容性评估。

## 发布与安装

新版仅作为目标环境验收候选包，不能标作正式验收完成。不要手工删除旧版。安装器保留配置、数据库和上一版本；正常回滚不恢复旧数据库，避免丢失升级后项目。

Windows 或 Linux 可从项目根目录运行 `npm run release -- --version <新版本号>`。实际候选包与命令以交付说明为准；服务端不依赖 Windows 原生模块，包内不包含工作区或数据库。
